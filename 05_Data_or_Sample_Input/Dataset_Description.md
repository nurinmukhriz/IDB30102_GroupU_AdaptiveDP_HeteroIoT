Dataset Description

1. Proposed Dataset

The research will use a publicly available IoT cybersecurity
dataset for the proof-of-concept evaluation.

N-BaIoT and ToN-IoT are currently considered as potential
dataset candidates because they contain IoT-related network
and cybersecurity data.

The final dataset will be selected based on:

- Relevance to IoT cybersecurity
- Availability of attack-related data
- Suitability for Federated Learning
- Feature suitability
- Suitability for non-IID data distribution
- Suitability for simulated heterogeneous IoT clients


2. Intended Use

The selected dataset will be used as input for the proposed
Federated Learning experiment.

The dataset will be preprocessed and distributed among
multiple simulated IoT clients to represent heterogeneous
and non-IID conditions.

The data will then be used to compare Fixed Differential
Privacy with the proposed Adaptive Differential Privacy
approach.


3. Data Type

The proposed input consists mainly of IoT cybersecurity data,
including network-related features and attack-related data.


4. Dataset Availability

The complete dataset will be obtained from the official
source after the final dataset selection.

No confidential, private, sensitive or restricted dataset
will be uploaded to the GitHub repository.
